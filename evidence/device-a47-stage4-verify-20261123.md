## 真 bug 二：任务区冷启动丢任务（alpha.47 修复）
- alpha.46 上**之前创建的监控任务不显示**。根因：`SeatTaskRepository.init()`（从 Prefs 读回持久化任务）在 SeatPage 从未调用；任务只在同进程内存里活着，`aa force-stop`/重装后即"消失"（SeatMonitorPage 有调 init，但用户没先进那个页）。
- 修复：`SeatPage.aboutToAppear` 中 `getTaskRepository().init().then(() => this.syncTasks())`；test-seatlist +1 守卫，改回旧写法拆红确认红。
- **alpha.47 复验（`a47-list.xml`）**：任务卡完整显示 `监控` / `等待中` / `中厅` / `2026-11-23 08:00 - 22:30` / `已等待 24 分钟 · 尝试 0 次 · 尚未尝试` ✅。
