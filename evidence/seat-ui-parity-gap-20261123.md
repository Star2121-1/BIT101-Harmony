# 鸿蒙座位模块 vs BIT101-S（Android）UI/功能差距盘点（2026-11-23）

## 结论先说
**不是"全部原样迁移"——鸿蒙座位页与 Android 是两套不同架构，差距是架构级的，不是小修小补。**
“预约成功看不到结果”是这套架构差异的直接后果。

## 一、“预约成功看不到结果”根因（已查清，非数据 bug）
- 真机证据：滚到 184 条座位最底部后，「我的预约（1）｜001｜2026-11-23 10:36:40｜未签到｜取消」**确实在**，数据刷新正常。
- 根因：鸿蒙把「我的预约」埋在**预约 tab 的 184 条座位列表之后**，要滚 20+ 次才看得到；用户不会滚到那，以为没成功。
- Android：座位预约成功后 `onNavigateToTasks()` **直接跳到「列表」tab**，且「我的预约」SectionHeader 在列表 tab **最顶部**——一眼就看到。
- ⇒ 这不是刷新/接口 bug，是 UI 架构差异。

## 二、架构级差异（两个 tab 的含义完全不同）

| | Android（权威） | 鸿蒙现状 |
|---|---|---|
| 「预约」tab | **NewTaskScreen**：新建预约/监控任务（选日期→选区域→选座位→创建任务），**没有实时座位列表** | 三级选址 + 184 条实时座位列表 + 我的预约（全塞一起，长滚动） |
| 「列表」tab | **TaskListScreen**：违约卡 → **我的预约（顶部）** → 我的研讨间 → 预约任务(进行中/已结束) → 规则 | 违约卡 → 研讨间卡 → 任务卡 → 规则（**没有「我的预约」**） |
| 座位图 | **SeatMapScreen 独立详情页**（自带顶栏+底栏 ReserveBottomBar），从 NewTaskScreen 点「选择座位」进入 | 内嵌在「预约」tab 里，列表/点位两个 viewMode 切换，无独立详情页 |
| 预约动作流向 | 座位图点座→底栏「预约 XXX」→成功 snackbar →**自动跳「列表」tab**看结果 | 点座→底栏确认→成功提示留在原地，我的预约在列表最底部 |

## 四、app 整体（非座位）——用户问“是否全部原样迁移”
本盘点只覆盖座位模块。整体 UI/配色/其它模块（课表/话廊/我页/地图等）此前多轮做过对齐，但**不能声称“100% 肉眼无区别”**：
- Android 是真机 Material You 动态取色，鸿蒙是固定色表（此前已记录）；
- 各页仍有未真机验的项（见 ROADMAP）；
- 建议以“逐屏截图对照”方式继续，而非口头断言全对齐。

## 五、下一步建议（待用户拍板）
1. **最小修复**（解决用户当下痛点）：把「我的预约」从预约 tab 底部搬到「列表」tab 顶部（对齐 Android），预约成功后自动切到列表 tab 并刷新 ⇒ 立刻看到结果。改动小、风险低。
2. **完整架构对齐**：按 Android 重构为 NewTaskScreen / TaskListScreen / SeatMapScreen 三页 + 三种模式 + 选座模式 + 完整卡片。工作量大（接近重做座位模块）。
3. **视觉对比**：用户提议卸载重装对比。注意：install -r 覆盖即可，无需卸载；卸载会清空刚重登的座位会话/凭据（需重新登录+授权）。跨 App 视觉对比用同机双 App 逐屏截图即可，不必卸载。

## 六、视觉对比（2026-11-23 真机 + Android 权威截图）
对照材料：
- Android 权威：`BIT101-seat/docs/images/seat-form.png`（预约=新建预约表单）、`seat-map.png`（独立座位图详情页）
- 鸿蒙基准：`harmony/ui-ref/ref-05-seat-list.png`（旧平板基准，列表 tab，**无我的预约区块**——比 Android 1.12.0 落后）
- 鸿蒙真机：`evidence/harmony-seat-list-tab-20261123.jpeg`（列表 tab）、`tmp/myreservation.jpeg`（预约 tab 底部我的预约）

肉眼可见差异：
1. Android「预约」tab = 深蓝底色的"新建预约"表单（模式/日期/校区下拉/楼层平面图放大/区域chip/选择座位按钮）；鸿蒙 = 三级 chip + 184 条座位列表，视觉结构完全不同。
2. Android 座位图是独立全屏页（深蓝顶栏+服务端底图+椅子元素+底部工具栏）；鸿蒙是内嵌列表/点位切换，无独立页、无深蓝顶栏。
3. Android「列表」tab 顶部有"我的预约"SectionHeader（含今天还能取消几次）；鸿蒙列表 tab 没有，只有违约/研讨间/任务/规则。
4. Android 配色深蓝（Brand），鸿蒙默认 Brand 但组件布局差异远大于配色差异。

结论：视觉对比证实差距是整体的，不是配色或局部排版，符合第二节架构级判断。
