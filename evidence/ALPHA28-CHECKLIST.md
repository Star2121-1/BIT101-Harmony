# alpha.28 真机对照清单（连设备后逐项验）

> 设备：nova 14 Pro `4CY9K25614019980` ｜ 基线：BIT101-S 1.12.0（用户手机主 App，卓易通兼容层内）
> 方法：同机双 App 截图 + dumpLayout 设备坐标（截图是缩放显示，点击一律用 dump 坐标）
> ⚠️ 判断要能证伪：每一项写清「看到什么算过、看到什么算没过」

## 装机前置（必做）
1. versionCode 27 → 29（28 已在代码里，装机提升到 29 避免同版本静默拒装）
2. `assembleHap` → `hdc install -r`（**禁止 uninstall**，会清用户会话数据）
3. `bm dump -n cn.bit101.next | grep versionCode` 确认 = 29（不看 install 的 "success" 字样）
4. 前台切换已获永久授权，直接 `aa start` / 点按切换，不用问

## 逐项对照

### A. 默认配色（全局，最先验）
- [ ] **A1** 全新启动（或清了偏好）后首屏是 **Brand 深蓝**：页面底 `#F7F9FC`、强调 `#1B4F9C`、底部选中 pill `#DEE4EE`
  - 证伪：若仍是暖棕 `#FFF8F5`/青绿 `#FBF8F4` ⇒ 首帧初值或 ThemeStore 默认值没生效
  - 注意：若用户之前手动选过皮肤并被持久化，那应显示用户选的（不算失败），需先确认是否有存值
- [ ] **A2** 设置页「配色方案」显示 = BIT101经典配色（Brand），chip 选中态对

### B. 「图」Tab（新瓦片地图）
- [ ] **B1** 切到底栏「图」，地图瓦片能加载出校园（不是灰网格占位）
  - 证伪：满屏 `#DCDAD4` 灰格 ⇒ 瓦片请求失败（查网络/域名）
- [ ] **B2** 左上 5 颗按钮：设置(⚙) + 乡/村/珠/嘉；默认「乡」高亮（primary 实底）
- [ ] **B3** 点「村/珠/嘉」：高亮跟随切换 + 弹「已切换到中关村/珠海/嘉兴校区」+ 地图视野移动
- [ ] **B4** 点设置按钮 → 底部「缩放倍率 2.0」面板 + 滑杆；拖动滑杆地图缩放变化
- [ ] **B5** 右下角常驻「© OpenStreetMap contributors」（ODbL 许可要求）
- [ ] **B6** 地图能拖拽平移、双指缩放（WebView 内联引擎交互）

### C. 「网」Tab（WebView）
